UNDERSTAND ASCEND-PG

From power grid to security assessment

Follow the five stages to understand what the platform protects, tests and measures.

⚡WHAT ARE WE PROTECTING?

Power Grid

An electrical network containing buses, controllers, equipment and communication links.

→
▣HOW IS IT MONITORED?

PLC & SCADA

Controllers operate equipment while SCADA allows operators to monitor the system.

→
●WHAT DO WE TEST?

Cyber Attacks

The platform safely tests different attack techniques against the simulated environment.

→
◆HOW DO WE DEFEND?

Security Detection

The defensive system monitors activity and attempts to identify malicious behavior.

→
▥WHAT DO WE LEARN?

Security Assessment

The system records evidence, attack outcomes, severity and vulnerability measurements.

ATTACK LIFECYCLE

How one security test becomes evidence

1

Attacker

→
2

Target

→
3

Network Activity

→
4

Detection

The defensive system analyzes the activity.

→
5

Result

The attempt is recorded as completed, failed or timed out.

→
6

Security Assessment

The recorded evidence is used to evaluate security performance.

Technical concepts

PLC

Programmable Logic Controller — a computer that controls industrial equipment.

SCADA

Supervisory Control and Data Acquisition — software used to monitor and control industrial equipment.

MITRE ATT&CK

A structured catalogue used to classify cybersecurity attack techniques.

PPO / AI

An AI-based decision system used to select attack strategies.

Suricata

A network security tool that identifies suspicious network activity.

DVS

Defense Vulnerability Score — an ASCEND-PG metric used to summarize observed defense vulnerability.

CUSTOM TOPOLOGY

Use the existing bus/edge model: 1–50 buses, ordered bus_id values starting at 0, type slack/pv/pq, and edges referencing bus IDs. Addresses remain 10.0.0.(bus_id + 1); CORE host names remain plc1, plc2, etc. Bus names are metadata. Electrical edges are shown in PyVis; CORE uses the same communication links.

Use a unique custom_ name to create a saved topology. Saving the same name updates it. Selection is locked while the current CORE Session is active.
