Technical concepts

PLC

Programmable Logic Controller — a computer that controls industrial equipment.

SCADA

Supervisory Control and Data Acquisition — software used to monitor and control industrial equipment.

MITRE ATT&CK

A structured catalogue used to classify cybersecurity attack techniques.

PPO / AI

An AI-based decision system used to select attack strategies.

Suricata

A network security tool that identifies suspicious network activity.

DVS

Defense Vulnerability Score — an ASCEND-PG metric used to summarize observed defense vulnerability.

VISUAL BUILDER

Build an electrical topology

Add buses and transmission lines. Electrical values feed the canonical pandapower baseline; CORE communication hosts and hub links are generated separately.

Buses

Electrical lines

Firewall devices and policy

Add only real firewall devices. Interfaces define zones; ordered rules use the same normalized policy model as GNS3 imports.

Advanced / Raw JSON Editor

Use the custom bus/edge model plus an optional firewalls array. Firewall entries use the same interfaces, zones, address objects, services, ordered rules, ports, actions, and default policy model as imported GNS3 configuration. Buses remain limited to 1–50 with ordered bus_id values starting at 0 and type slack/pv/pq. Addresses remain 10.0.0.(bus_id + 1); CORE host names remain plc1, plc2, etc. Bus names are metadata. Electrical edges are shown in PyVis; CORE uses the same communication links.

Use a unique custom_ name to create a saved topology. Saving the same name updates it. Selection is locked while the current CORE Session is active.
